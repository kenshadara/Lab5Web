## H. Jawaban Pertanyaan Praktikum

### 1. Perbedaan console.log(), alert(), prompt(), dan textContent/innerHTML
- console.log() menampilkan informasi di Console browser.
- alert() menampilkan pesan dalam kotak dialog.
- prompt() meminta masukan dari pengguna.
- textContent mengubah teks elemen HTML, sedangkan innerHTML dapat mengubah isi HTML.

### 2. Perbedaan let dan const
let digunakan untuk variabel yang nilainya dapat diubah. const digunakan untuk variabel yang tidak dapat ditetapkan ulang.

### 3. Perbedaan operator == dan ===
== membandingkan nilai dengan kemungkinan konversi tipe data, sedangkan === membandingkan nilai sekaligus tipe datanya.

### 4. Fungsi if–else dan switch
if–else digunakan untuk menjalankan instruksi berdasarkan kondisi. switch digunakan untuk memilih tindakan berdasarkan nilai tertentu.

### 5. Fungsi parameter dan return
Parameter menerima data yang diberikan kepada function. return mengembalikan hasil dari function.

### 6. Fungsi document.getElementById()
Method ini digunakan untuk memilih elemen HTML berdasarkan atribut id.

### 7. Validasi nama dan nilai 0–100
Program memeriksa agar nama tidak kosong dan nilai berada pada rentang 0 sampai 100. Jika input tidak sesuai, program menampilkan pesan bahwa data tidak valid.
